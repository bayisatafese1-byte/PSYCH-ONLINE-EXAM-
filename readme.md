# General Psychology – Chapter One Exam

## Chapter
Essence of Psychology

## Overview
A challenging 40-question multiple-choice practice examination
based on Chapter One of the General Psychology module.

## Topics Covered
- Definition of psychology
- Behavior and mental processes
- Goals of psychology
- Historical development of psychology
- Structuralism and functionalism
- Psychoanalytic, behavioral, humanistic, cognitive and biological perspectives
- Branches and subfields of psychology
- Research methods
- Correlation and experimental research
- Independent and dependent variables
- Experimental and control groups
- Scientific research process

## Project Files

- `index.html` – Main exam page
- `style.css` – Design and responsive layout
- `script.js` – Questions, scoring and exam functionality
- `README.md` – Project documentation

## How to Run

1. Create a folder named `psychology-chapter-1-quiz`.
2. Save all four files inside that folder.
3. Open `index.html` using a web browser.
4. Answer the 40 questions.
5. Click Submit Exam to see your score and explanations.

## Features

- 40 challenging multiple-choice questions
- Four answer options per question
- Automatic score calculation
- Progress bar
- Correct and incorrect answer highlighting
- Explanations after submission
- Reset and retry functionality
- Responsive design for mobile and desktop
- Footer section

## Requirements

A modern web browser is sufficient.
No installation, server, or internet connection is required.

## Purpose

This project is intended for self-assessment, revision,
and examination preparation.
